# Example Review Workflow

Use this Skill only for synthetic example inputs.

1. Read `references/risk-levels.md` before choosing a classification.
2. Classify the input as low, medium, or high.
3. Return the classification and a short explanation based on the reference.

The reference is supporting information, not authoritative policy.
